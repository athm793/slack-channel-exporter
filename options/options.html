How to connect your Google Sheet ›
  1. Open (or create) the Google Sheet you want to write to.
  2. Click Extensions → Apps Script.
  3. Delete any existing code, paste the script below, and press Save.
  4. Click Deploy → New deployment.
    Set Type = Web app, Execute as = Me,
    Who has access = Anyone. Click Deploy.
  5. Authorise when prompted, then copy the Web app URL.
  6. Paste it in the field above and click Save.
